# 蔵書レファレンスナビ（検索体験検証版）

モンスターライブラリーの「蔵書原簿CSV」を読み込み、具体的な書名が分からなくても、気分・悩み・目的・テーマから学校蔵書を探すためのWebアプリ・プロトタイプです。

## できること

- モンスターライブラリー特殊形式CSVを無加工で読み込み
- 3万冊規模の蔵書をWeb Workerで処理し、画面停止を避ける
- 日本語の相談文からテーマを推定してハイブリッド検索
- 小説/知識系、長さ、出版年代の条件追加
- 「ど真ん中 / 意外な一冊 / 読みやすい入口」の3方向推薦
- 「なんか違う」から条件を足して再検索
- 請求記号、登録番号、出版社、出版年等を表示
- CSVはIndexedDBに保存し、同じ端末では再読込を省略
- PWA対応、オフライン起動対応
- 外部AI API・外部JavaScriptライブラリ不使用

## 最初から入っているデータ

公開版を軽く保ちながら検索体験を試せるよう、実CSVから50冊の代表サンプルを同梱しています。

本番利用時は画面右上の「蔵書データ」から、モンスターライブラリーから書き出したCSVを選択してください。確認済みの実CSVでは30,973冊を認識できます。

## GitHub Pagesで公開

`index.html` がリポジトリ直下にある構成です。GitHub Pagesでは `main` ブランチ / root を公開対象にしてください。

## 現在の検索精度について

これは検索体験を検証する第1プロトタイプです。現在は、CSVに存在する以下の情報を使っています。

- 書名
- 著者
- 出版社
- 出版年
- ページ数
- 請求記号
- 登録番号

あらすじ、件名、Mood、読後感等は元CSVに存在しないため、現段階ではAIが知ったふりをして生成しません。

次段階では、NDL等との書誌照合や日本語意味検索を追加し、「重すぎない」「余韻がある」「説教っぽくない」等の検索精度を比較検証する想定です。

## データ方針

モンスターライブラリーを正式な蔵書管理の正本とし、このアプリでは貸出・返却・利用者管理を行いません。生徒名や貸出履歴を取り込む設計にもしていません。
