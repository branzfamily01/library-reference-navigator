# 蔵書レファレンスナビ — Stage 2

モンスターライブラリーの「蔵書原簿CSV」を読み込み、具体的な書名が分からなくても、気分・悩み・目的・テーマから学校蔵書を探すためのWebアプリです。

## Stage 2で追加したこと

- 自然文からテーマだけでなく Mood / 読み心地も抽出
- 「前向き」「重すぎない」「余韻」「穏やか」「没頭」「緊張感」「読みやすさ」等を検索条件化
- まず全蔵書を端末内で高速検索し、候補を絞る
- 精度アップON時のみ、候補本の**書名・著者**をGoogle Booksへ照会
- 取得できた紹介文・カテゴリ・ISBN・ページ数を端末内にキャッシュ
- 紹介文・カテゴリを使って候補を再順位付け
- 推薦理由に「蔵書情報」「書誌補完」「紹介文照合」の根拠レベルを表示
- 外部書誌取得に失敗・オフラインの場合は自動でローカル検索へフォールバック
- 検索文そのものは外部へ送信しない

## 維持している機能

- モンスターライブラリー特殊形式CSVを無加工で読み込み
- 3万冊規模の蔵書をWeb Workerで処理
- 小説/知識系、長さ、出版年代の条件追加
- 「ど真ん中 / 意外な一冊 / 読みやすい入口」の3方向推薦
- 「なんか違う」から条件を足して再検索
- 請求記号、登録番号、出版社、出版年等を表示
- CSVはIndexedDBに保存し、同じ端末では再読込を省略
- PWA対応、オフライン起動対応

## データとプライバシー

モンスターライブラリーを正式な蔵書管理の正本とし、このアプリでは貸出・返却・利用者管理を行いません。生徒名や貸出履歴を取り込む設計にもしていません。

書誌精度アップをONにした検索では、候補本の書名・著者だけをGoogle Books APIへ照会します。利用者が入力した相談文そのものは送信しません。取得済み書誌情報は端末内のIndexedDBへ保存し、次回以降の検索で再利用します。

## 検索の考え方

1. **ローカル候補抽出** — 書名、著者、出版社、請求記号、NDC相当の大分類、テーマ辞書、Mood辞書で候補を絞る
2. **書誌補完** — 上位候補だけ紹介文・カテゴリ・ISBNを照合
3. **再順位付け** — 相談から抽出したテーマ/Moodと紹介文・カテゴリの一致を加点
4. **3方向推薦** — ど真ん中 / 意外な一冊 / 読みやすい入口

Moodは紹介文等から検索用に推定する指標であり、作品への価値判断ではありません。
